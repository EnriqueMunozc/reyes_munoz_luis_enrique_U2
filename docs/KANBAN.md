## Reglas del Tablero

- Cada fase debe tener una rama propia o una rama de funcionalidad.
- Una tarea pasa a En revision cuando ya tiene cambios listos y diff revisado.
- Una tarea pasa a Terminado solo cuando la evidencia exista y no sea simulada.
- Las capturas y enlaces de cloud host se agregaran hasta que el despliegue sea real.
