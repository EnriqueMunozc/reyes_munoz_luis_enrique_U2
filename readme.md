# Grand Line Store

Tienda web ficticia de artículos de anime inspirados en One Piece.

## Objetivo

Desarrollar una aplicación web escolar con base de datos,
inicio de sesión, catálogo y administración de productos,
utilizando Git y GitHub para el control de versiones.

## Funciones previstas

- Catálogo de productos.
- Inicio de sesión.
- CRUD de productos y categorías.
- Carrito y pedidos ficticios.

## Requisitos de la actividad

1. Justificación de las plataformas y herramientas de versionamiento.
2. Flujo de trabajo del control de versiones.
3. Parámetros de configuración de las plataformas y herramientas.
4. Enlace del repositorio en GitHub y captura del sitio funcionando
   en un cloud host.

## Estado del proyecto

Etapa inicial: creación del repositorio y documentación.
